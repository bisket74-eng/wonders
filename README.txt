WONDERS — GITHUB PAGES FILES

1. Create a GitHub repository named Wonders.
2. Upload every file in this folder to the top level of that repository.
3. In GitHub, open Settings > Pages.
4. Set the source to Deploy from a branch, choose main and /(root), then Save.
5. Open the GitHub Pages address after deployment finishes.

The app uses the same browser-safe Supabase project connection as Chaser.
No SQL file is required for this version because rooms, chat, player presence,
and game updates use Supabase Realtime channels.
